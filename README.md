# SmartPet - Smart Pet Health & Emergency Management System

A B.Tech college project frontend for managing pet health records, vaccinations, medical history, vet visits, reminders, and emergency information.

## Tech Stack

- React.js
- Vite
- JavaScript
- React Router
- localStorage (no backend)

## How to Run

```bash
npm install
npm run dev
```

Open the URL shown in the terminal (usually http://localhost:5173).
